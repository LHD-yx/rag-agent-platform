# 评测集构建指南

> 目标：100 条以上，覆盖 6 类问题，gold 标注可验证。
> 配套脚本：`scripts/gen_eval_candidates.py`（生成候选）、`scripts/check_eval_set.py`（校验）。

---

## 一、格式说明

`data/eval/eval_set.jsonl`，每行一条 JSON：

```json
{"query": "设备无法开机怎么办", "gold_chunk_ids": ["d1-0-1"], "gold_doc_ids": ["d1"], "category": "故障排查"}
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `query` | 是 | 用户问题 |
| `gold_chunk_ids` | 二选一 | 能回答该问题的**片段 id**（最精确，推荐） |
| `gold_doc_ids` | 二选一 | 只知道在哪篇文档时用，粒度粗 |
| `category` | 建议 | 便于检查分布，如「事实查找」 |
| `multi_hop` | 可选 | 多跳问题标 `true` |
| `unanswerable` | 可选 | 文档里本来答不了的问题标 `true`，**不标 gold** |

多跳问题可以写多个 gold（来自不同文档）：

```json
{"query": "X 型号的电源模块能用在哪些型号上", "gold_chunk_ids": ["d1-0-2", "d5-1-0"], "multi_hop": true}
```

## 二、问题类型与建议分布

以 100 条为例：

| 类型 | 条数 | 考察什么 | 示例 |
|---|---|---|---|
| 事实查找 | 25 | 召回精度 | "额定电压是多少" |
| 操作指引 | 20 | 语义匹配 | "如何恢复出厂设置" |
| 故障排查 | 20 | 关键词 + 语义 | "无法开机怎么办" |
| 对比选择 | 10 | 多片段聚合 | "X 和 Y 有什么区别" |
| 多跳组合 | 10 | 多轮检索能力 | "换了主板还保修吗" |
| 口语化 / 缩写 | 8 | 查询改写效果 | "开不了机咋整" |
| 拒答类 | 7 | 幻觉控制 | "竞品 Z 的价格是多少" |

**拒答类不可省**：只测"能答对"是不够的，还要能测"答不了的时候会不会编"。没有拒答样本，就报不出"低置信检出率"这个指标。

## 三、四步构建法

### 第 1 步：自动生成候选（约 10 分钟）

```bash
python scripts/gen_eval_candidates.py --limit 120 --per-chunk 1
```

脚本从已有切片里均匀抽样，用 LLM 为每个片段生成 1 个问题，并**自动填好 `gold_chunk_ids`**，输出：

- `data/eval/candidates.jsonl` —— 候选评测集
- `data/eval/candidates_review.md` —— 人工复核清单（带片段预览）

> 这两个是**中间产物**，不进仓库；跑一次脚本就会重新生成。

### 第 2 步：人工筛选与改写（约 1~2 小时）

逐条判断：

- 问题是否像**真实用户**会问的？（"根据文档内容回答…"这类一律改写）
- 问题是否**能由该片段回答**？（不能就换片段或删除）
- 是否照抄了文档标题？（改写得更口语化）

### 第 3 步：手工补两类（约 30 分钟）

自动生成**很难**产出「多跳组合」和「拒答类」，必须手工补：

- 多跳：把两个片段的答案组合起来才能回答的问题；
- 拒答：文档里确实没有答案的问题（竞品信息、市场数据、闲聊）。

### 第 4 步：校验（约 1 分钟）

```bash
python scripts/check_eval_set.py
```

会检查格式、gold 是否真实存在、重复问题、分布是否偏斜。

## 四、标注规则

1. **不要先看检索结果再标注**——否则会不自觉地把"检索到的"当成"正确的"（确认偏差），指标会虚高，而且不可复现；
2. gold 要选**真正能回答问题**的片段，不是"出现过关键词"的片段；
3. 答案分散在多处时，**多个 gold 都标上**；
4. 拒答类**不要标 gold**，并且要设 `unanswerable: true`；
5. 一个问题只问一件事："X 怎么装、多少钱、保修多久"应拆成三条；
6. 出题不要**集中在同一篇文档**，否则检索随便都能命中，指标虚高；
7. 建议留出**调参集与验证集**（例如 80 条调参 + 20 条最终验证）——用同一批数据反复调参会过拟合。

---

## 五、验收清单

- [ ] 条数 ≥ 100
- [ ] 事实查找类不超过 30%（否则指标虚高）
- [ ] 拒答类 10~15 条
- [ ] 多跳类 ≥ 8 条
- [ ] 口语化 / 缩写类 ≥ 5 条
- [ ] 单个文档来源的问题占比 < 15%（避免评测集偏斜）
- [ ] `python scripts/check_eval_set.py` 全部通过
- [ ] 没有重复问题
