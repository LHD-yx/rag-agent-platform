# X3-75 安装与调试指南

文档编号：XL-IN-X3-75　｜　版本：V2.1　｜　更新日期：2026-04-10

适用型号：X3-75　｜　发布单位：星澜智能科技有限公司

## 一、安装环境确认

- 确认安装位置具备电源插座与信号接口。
- 避免阳光直射、潮湿与强磁场环境。
- 墙面安装需为承重墙，轻质隔墙请加装背板。
## 二、安装步骤

### 2.1 底座安装

将主机平放在包装泡沫上，用 4 颗随机螺丝固定底座支架并拧紧。

### 2.2 壁挂安装

按 VESA 孔位安装挂架，建议两人协作抬装，避免受力不均。

### 2.3 信号连接

| 外设 | 推荐接口 | 说明 |
|---|---|---|
| 机顶盒 | HDMI 1 | 支持 4K 60Hz |
| 游戏主机 | HDMI 2 | 建议开启游戏模式降低延迟 |
| 回音壁 | HDMI eARC | 由回音壁解码杜比音轨 |
| U 盘 | USB 3.0 | 支持 FAT32 / exFAT 格式 |

## 三、调试要点

- 开机后进入「画质向导」按房间光线选择模式。
- 使用网络测速确认带宽，4K 在线播放建议 ≥50Mbps。
- 首次使用建议执行一次系统升级。
## 四、验收检查

| 检查项 | 标准 |
|---|---|
| 画面 | 纯色画面无亮点、竖线 |
| 声音 | 左右声道均有输出 |
| 网络 | WiFi 与有线均可连通 |
| 遥控 | 各按键响应正常 |
