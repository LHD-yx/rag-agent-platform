## 一、基本参数

| 项目 | 参数 |
|---|---|
| 产品型号 | A5-50 |
| 产品定位 | 家用主流智能电视 |
| 屏幕/投射 | 50 英寸 |
| 分辨率 | 3840×2160（4K） |
| 面板/光源 | IPS / VA 直下式 |
| 刷新率 | 60Hz |
| 内存 | 2GB + 32GB |
| 音频 | 2×10W 全频 |
| 电源 | 220V~ 50Hz |
| 工作温度 | 0℃~40℃ |
| 存储温度 | -20℃~60℃ |
| 整机功耗 | 438W（典型值） |
| 待机功耗 | ≤0.5W |

## 二、接口配置

- HDMI 输入 × 3（支持 HDMI 2.1 与 eARC）
- USB 3.0 × 1、USB 2.0 × 1
- 光纤音频输出 × 1、有线网口 × 1（10/100M）
- 天线输入 × 1、AV 输入 × 1
## 三、执行标准

本产品符合 GB 8898《音频、视频及类似电子设备安全要求》与 GB 9254 电磁兼容标准。

## 四、注意事项

- 请使用原厂电源线与适配器。
- 避免与大功率电器共用插排。
- 搬运时请勿按压屏幕或光机镜头。
