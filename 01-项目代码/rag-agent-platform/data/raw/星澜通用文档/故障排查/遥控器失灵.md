# 遥控器失灵排查指南

文档编号：XL-FT-005　｜　版本：V2.1　｜　更新日期：2026-04-10

适用产品：星澜电视 / 投影 / 智能盒子　｜　发布单位：星澜智能科技有限公司

## 一、现象描述

- 按键无反应
- 需贴近才有效
- 语音无法唤醒
## 二、排查步骤

### 1. 更换电池

使用全新 AAA 电池并注意正负极。

### 2. 重新配对

长按「主页」+「返回」5 秒进入配对。

### 3. 排除遮挡

清理红外接收窗前遮挡物。

### 4. 摄像头自检

用手机摄像头对准红外发射头，按键无紫光说明已损坏。

## 三、可能原因

| 可能原因 | 处理方式 |
|---|---|
| 线缆或接口接触不良 | 更换线缆或接口，重新插紧 |
| 设置项配置错误 | 按本文步骤逐项核对设置 |
| 硬件模块异常 | 需返厂或上门检测更换 |

## 四、何时需要报修

完成以上排查仍无法解决时，请拨打 400-826-1068 或通过「星澜服务」App 提交工单，城区将在 48 小时内安排上门检测。

> 请勿自行拆机，私自拆机会导致保修失效。
